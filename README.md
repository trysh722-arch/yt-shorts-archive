# 유튜브 최신 Shorts 선반 자동 캡처

검색어로 유튜브를 열어 `OOO의 최신 Shorts 동영상` 선반을 찾고, `더보기`를 눌러 전부 펼친 상태를 캡처한다.
깃허브 서버가 대신 돌리므로 **내 PC는 꺼져 있어도 된다.**

## 나오는 것 (1회 약 3.2MB)

| 파일 | 내용 |
|---|---|
| `01_검색상단.jpg` | 검색 결과 첫 화면 |
| `02_선반_접힘.jpg` | Shorts 선반 접힌 상태 |
| `03_선반_전체.jpg` | 더보기 펼친 선반 전체 (긴 세로 1장) |
| `03_선반_part01~NN.jpg` | 위를 화면 높이(1080)로 자른 것 |
| `meta.txt` | 캡처 시각, 선반 제목, Shorts 개수, 완전펼침 여부 |

폴더명은 `배달의민족_260914_0800` 형식(한국시간).

## 전체 흐름

```
08:00 / 20:00  깃허브 액션이 캡처 → snapshots 브랜치에 최근 7회분 보관
08:20 / 20:20  나스가 그걸 받아서 지정 폴더에 쌓음 (나스에는 전부 누적)
```

나스가 IP 192.168.10.x 라 외부에서 밀어넣을 수 없다. 그래서 **나스가 가져오는** 방향이다.
포트포워딩·DDNS 필요 없고 나스 계정을 깃허브에 넣지 않아도 된다.

## 설치

### 1. 깃허브 저장소

1. 새 저장소 만들기 (비공개 권장).
2. 이 폴더 전체를 올린다. `capture.py`, `.github/workflows/capture.yml` 두 개가 핵심.
3. Actions 탭 → `youtube-shorts-capture` → `Run workflow` 로 **먼저 수동 1회 실행**해서 성공하는지 본다.
   - 성공하면 `snapshots` 브랜치가 생기고 결과가 들어간다.
   - 실패하면 Actions 화면의 `capture-N` 첨부파일에 `99_실패화면.jpg` 가 들어있다.

검색어를 바꾸려면 `capture.yml` 의 `default: '배달의 민족'` 을 고치거나, 수동 실행 시 입력창에 넣는다.

### 2. 비공개 저장소면 토큰 만들기

깃허브 → Settings → Developer settings → Personal access tokens → Fine-grained tokens
→ 해당 저장소만 선택, 권한은 `Contents: Read-only` 하나면 된다. 만든 문자열을 복사.

### 3. 시놀로지 나스

1. DSM → 제어판 → **작업 스케줄러** → 생성 → 예약된 작업 → **사용자 정의 스크립트**
2. 사용자: `root`
3. 일정: 매일, 시간 `08:20` 으로 하나 만들고, 같은 걸 `20:20` 으로 하나 더 만든다.
4. 작업 설정 → 사용자 정의 스크립트 칸에 `nas_pull.sh` 내용을 붙여넣고 위쪽 3줄을 채운다.
   - `REPO` : `깃허브아이디/저장소이름`
   - `TOKEN` : 2번에서 만든 토큰 (공개 저장소면 빈칸)
   - `DEST` : 저장할 나스 경로. 예) `/volume1/메타버즈/마케팅/유튜브캡처`
5. 저장 후 목록에서 선택 → **실행** 을 눌러 수동 테스트.
6. `DEST/_sync.log` 에 `OK 누적 폴더 N개` 가 찍히면 성공.

## 내 PC에서 그냥 한 번 돌려보기

```
cd Desktop\클로드\yt_shorts_capture
python capture.py "배달의 민족" out
```

## 알아둘 것

- **로그인 안 한 상태**로 캡처한다. 개인화가 없어 회차끼리 비교가 되지만, 내 브라우저 화면과 순서가 다를 수 있다. vidIQ 같은 확장 배지도 안 나온다.
- 깃허브 크론은 서버가 붐비면 몇 분 늦게 돈다. 보통 5분 이내.
- 미국 서버에서 접속하므로 `hl=ko&gl=KR` 로 한국·한국어를 강제한다. 그래도 유튜브가 서버 IP를 막으면 실패할 수 있다. 이때 `meta.txt` 에 `ERROR: ... 선반 못 찾음` 이 남고 `99_실패화면.jpg` 로 원인을 본다.
- 유튜브가 화면 구조를 바꾸면 `capture.py` 위쪽의 `SHELF_SEL`(현재 `grid-shelf-view-model`) 을 고쳐야 한다. 2026-09-14 기준값이다.
- `meta.txt` 의 `완전펼침확인(간략히버튼)=YES` 는 더보기가 끝까지 펼쳐졌다는 뜻이다. `NO` 면 일부만 담긴 것이다.
- 깃허브 무료 한도는 월 2,000분. 이 작업은 회당 약 2분, 월 약 120분이라 여유롭다.
